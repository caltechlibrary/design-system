

# design-system

design-system provides Caltech Library's branded web components, for use on Caltech Library sites and applications.

The following are the components currently provided.

`footer-global`
: This component provides a standard footer with detailed information about the library

`footer-global-lite`
: This component provides a lighter weight version of the `footer-global` component

`card-layout`
: This component provides a three-card layout for displaying featured content with images, titles, descriptions, and links.

Generic, unbranded components are in [CL-web-components](https://github.com/caltechlibrary/CL-web-components).
